# נבחרת — למידה צוותית

PWA לצוות אולפנת צביה מעלה אדומים (סמל מוסד 141176): צ׳קליסט יכולות לפי תקופות, למידה, מפגשים, CMS ודשבורד הנהלה.

## הרצה מקומית

```bash
npm install
npm run dev
```

הכתובת: `http://localhost:5173`

## כניסה

1. סמל מוסד `141176`
2. מייל אולפניסטי, או חיפוש לפי שם
3. הטופס נפתח בלי סיסמה
4. למידה / פרופיל / מפגשים — כניסת גוגל (בהדגמה מקומית בלי Firebase: אישור אותו מייל)

אדמין: `039698329@tzviama.com` ו־`chepti@gmail.com`

## Firebase

העתיקי `.env.example` ל־`.env` ומלאי את המפתחות. בלי מפתחות האפליקציה עובדת על `localStorage` באותו דפדפן.

אחרי יצירת הפרויקט:

- Authentication → Google
- Firestore + הכללים מ־`firestore.rules`
- Hosting (או העלאת `dist/` ל־`tzviama.com/learn/`)
- Functions (אופציונלי) מתיקיית `functions/`

## תוכן התחלתי

טיוטה מלאה רק ל־Classroom (אלול–תשרי). שאר הכלים ריקים ומוכנים ב־CMS.

רשימת המורות יובאה מ־`/צוות/מורים` — שמות ומיילים בלבד, בלי סיסמאות.
