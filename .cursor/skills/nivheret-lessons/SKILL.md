# שיעורי נבחרת

כשהמשתמשת מבקשת ליצור שיעור — מנסחים בעברית חמה וקצרה, ואז כותבים לתוך הנתונים (CMS / `src/data/seed.ts` / Firestore דרך האפליקציה), לא רק מציגים טיוטה בצ'אט.

## מבנה שיעור

- `title` — משפט פעולה («איך פותחים כיתה»)
- `body` — 4–8 משפטים או צעדים ממוספרים. בלי מונחים מיותרים. פונות לרבות.
- `videoUrl` — רק אם נמסר קישור embed
- `capabilityId` — חייב להתאים ליכולת קיימת
- `quiz` — 2–3 שאלות, לכל אחת 3 תשובות, `correctIndex` אחת נכונה
- `autoCompleteOnQuiz: true`

## שאלות

- בודקות הבנה מעשית, לא שינון סיסמאות
- המסיחים הם טעויות סבירות של מורה מתחילה
- בלי «כל התשובות נכונות»
- אחרי ניסוח — מוסיפים ב־CMS (`addLesson` / עדכון `lessons`) או ב־seed אם התוכן עדיין לא בענן

## איך עובדים בשיחה

1. המשתמשת נותנת נושא, נקודות, או צילום מסך.
2. לנסח שיעור + שאלות, להציג בקצרה לאישור אם התוכן רגיש.
3. לשמור באפליקציה (עדיף דרך מבנה הנתונים הקיים) ולפרוס אם צריך.
4. לא להמציא נהלי אולפנה. אם חסר פרט — לשאול או לכתוב צעד כללי.

## טון

עברית RTL, צוות אולפנה, מעשית, בלי שיווק.
